>How AeroML Works

Normally, custom airfoil optimization requires executing slow numerical solvers (like XFOIL) repeatedly. AeroML bypasses this iteration bottleneck by training a fast, three-seed Deep MLP ensemble as a surrogate model of viscous XFOIL aerodynamic simulations.

Using this forward surrogate model, the reverse engine optimizes design targets using multi-restart batched Adam gradient searches across a 16-dimensional PCA-compressed geometry space, allowing you to synthesize custom high-efficiency profiles in milliseconds.

Model Accuracy

Model metrics evaluated on held-out test datasets. Note that CdMin remains the hardest physical target to capture due to boundary-layer separation sensitivity.
